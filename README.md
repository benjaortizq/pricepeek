<h1 align="center">PricePeek</h1>

<p align="center"><b>Comparador de precios para Costa Rica</b></p>

PricePeek reúne en un solo lugar los precios de un mismo producto en distintos comercios del país, obtenidos mediante *web scraping*, para que el consumidor encuentre la mejor opción sin revisar tienda por tienda. Los precios se actualizan automáticamente de forma periódica con GitHub Actions, así que la información se mantiene al día sin intervención manual. Permite generar comparaciones exportables a PDF, guardar productos en una lista de deseos con alertas de precio, dejar reseñas y usar la interfaz en español o inglés. Incluye un panel empresarial para que los comercios gestionen su catálogo y un panel administrativo para moderar contenido.

**Tecnologías:** Python, Django, PostgreSQL (Supabase), Tailwind CSS, GitHub Actions, Jira, Figma.
